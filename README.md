# Portfolio — Ndiaga Seye

Portfolio professionnel responsive construit avec React, Vite et Tailwind CSS v4 (styles personnalisés dans `src/style.css`). Il propose une présentation bilingue FR/EN, les compétences, les projets et un contact par e-mail.

## Prérequis
- Node.js 20 ou supérieur
- npm

## Installation et lancement
Dans un terminal, depuis le dossier `portfolio-ndiaga` :

```bash
npm install
npm run dev
```

Ouvrir l'adresse locale affichée par Vite (généralement `http://localhost:5173`).

## Générer la version de production
```bash
npm run build
npm run preview
```

Le site construit se trouve dans `dist/`.

## Personnalisation avant publication
1. Vérifier les textes, technologies et statuts des projets dans `src/main.jsx`.
2. Remplacer le bloc avatar `NS` par une photo professionnelle si souhaité.
3. Remplacer le lien LinkedIn générique par l'URL de votre profil réel.
4. Ajouter les liens de démonstration et dépôts propres à chaque projet quand ils sont disponibles.
5. Vérifier l'adresse e-mail de contact.

**Note sur les projets :** DND et Gestion des dépenses sont présentés comme projets réalisés. Le transfert Wave → Orange Money est indiqué comme étant en conception ; aucune intégration réelle de transfert d'argent n'est revendiquée.
